# Notes on ChatGPT, Codex and GitHub installation

**Project settings:** Open the existing Tutoring-Allen Project → `•••` → Project settings. Append `01_CHATGPT_PROJECT_INSTRUCTIONS_APPEND.md` rather than replacing existing instructions. Keep textbook screenshots, parent feedback and approved materials already in the Project.

**Codex:** This kit is designed to be applied at the root of the GitHub repository `loganrossbryant-ai/EAL-Game` with a safe feature branch and review. Root `.agents/skills/` is intentional: Codex project skills are discovered from this location. `tutoring-games/AGENTS.md` scopes instructions to the tutoring subtree while preserving the repository's existing secondary school conventions.

**When you cannot attach the ZIP directly to Codex Cloud:** Use GitHub web Upload files to place the *setup kit ZIP itself* on a new temporary feature branch, then ask Codex to unpack it into the repo root, run validators, and remove only the temporary setup archive within that branch. This is a workflow alternative, not a claim that Codex cloud shares ChatGPT's sandbox files.

**Do not upload the ZIP to this Project as a replacement for individual source docs without updating Project settings.** A Project source archive does not automatically convert its members into persistent Project instructions.

**Different repos:** Current EAL-Game is the editable design/source repository. The previously referenced `hello-earth-demo` hosted game is not proven equivalent to the exact final Lesson 4 release. Do not replace it until tested and approved.

**If browser limitation:** Codex Cloud runs supported tasks in the cloud without installing a desktop app, but GitHub repository permissions and environment configuration may require an explicit connection if the task cannot see a repository. Use the Help Center if necessary.
