# EAL Adventure Game Studio

**Start here:** [Studio production index](studio/README.md) · [New-game kickoff](studio/START_NEW_GAME.md) · [Current Broken Bridge checkpoint](studio/checkpoints/BROKEN_BRIDGE_CONTINUE.md)

This public repository separates **approved reference games**, **working experiments**, and **eventually reusable game-engine modules**. Never mistake a design template or bundled HTML for approved, editable engine source.

**Current status (2026-11-24):** The Broken Bridge **v0.4.0 is a REVIEW BUILD, not an approved gold standard**. The reusable Adventure Engine has not yet been extracted or accepted. Do not build a new unit by blindly copying its visuals or lessons.

## Locations and responsibilities
- `AGENTS.md`, `GAME_BRIEF.md`: Codex-wide instructions and secondary EAL context.
- `studio/`: **one authoritative shared production workflow** for all future school EAL and tutoring games: art, interaction, curriculum, audio, acceptance, and start-new-game templates.
- `tutoring-games/`: supplementary instructions for tutoring/elementary/adult use (never impose grade 9–12 assumptions).
- `docs/`, `reference/`, `scripts/restore_v6.py`: preserved secondary v6 benchmark and original integrity gates.
- `games/_v8_trial/`: archived engineering trial, not a commercial-quality accepted engine.
- `releases/`: do not change existing approved artifacts or URLs.
- **Working branches:** `codex/broken-bridge-v0.4.0-review` is the most recent Broken Bridge build branch; `codex/broken-bridge-25d-prototype` is an older planning branch.
- **Original Zig benchmark:** found on `codex/tutoring-game-setup`; do not claim main contains its archived ZIP until separately imported and verified.
- Other active projects and historical branch names are catalogued in [studio/STUDIO_REGISTRY.md](studio/STUDIO_REGISTRY.md).

This repo is public. **Never commit student identities, textbook scans, private classroom/parent documents, credentials or licensed content without permission.**

For a new creative idea, begin with [studio/START_NEW_GAME.md](studio/START_NEW_GAME.md), supply the actual authorized lesson sources privately and use the verified game engine when one exists. No speculative quality assurances.
