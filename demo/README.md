# Play Signal

1. Open **Signal-Play.html** in this GitHub folder.
2. Click **Download raw file** (the down-arrow button above the code).
3. Open the downloaded file in Chrome or Edge. No unzip, installation, account, or development server is needed.

Move with WASD, arrows, or floor clicks. Click a glowing marker, or approach it and press E. Escape closes interactions. Begin with Maya by the right-hand desk. Read the noticeboard, laptop campaign, and email inbox, then return with an evidence-based recommendation.

Student progress saves only in that browser. Field notebook can export your writing. Audio is optional.

This is a self-contained copy of the first playable chapter. The source is in the repository root. To refresh this file after changes, run `npm ci`, `npm run build`, and `node scripts/package-demo.mjs`. Original textbook pages have not been supplied, so vocabulary alignment remains provisional.
