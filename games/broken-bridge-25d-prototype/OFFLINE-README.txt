THE BROKEN BRIDGE • v0.3.0 • TEACHER REVIEW BUILD

Extract the ZIP into a folder. From that folder run:
  python3 -m http.server 8000 --bind 127.0.0.1
In a desktop browser open:
  http://127.0.0.1:8000/Broken-Bridge-v0.3.0.html

Keep the terminal open while playing. No Internet connection is needed.
Use the same browser and address when resuming locally saved progress.
Tap the trail or use the arrow keys. Tap landmarks to approach and interact,
or press E when nearby. Open Field log to export an anonymous JSON record.

The language is illustrative. Narration in the approved voice is pending.
iPhone hardware, WeChat and Home Screen installation are unverified.
