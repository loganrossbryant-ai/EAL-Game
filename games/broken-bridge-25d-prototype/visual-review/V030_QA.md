# The Broken Bridge v0.3.0 — teacher review record

**Status:** playable teacher-review candidate for one ranger-clearing section. Teacher creative acceptance is pending. The independent v0.2 audit informed this revision; it was treated as review evidence alongside the user's explicit scope.

## Visual comparisons

- **Observations in the running game.** The far forest shifts relative to the bank, a new canopy frames the top of the clearing, and the mossy boulder can sit in front of the scout. The registered bridge pair makes the void and loose line visible at opening scale. Board placement changes the deck before the rope completes it. The ford outcome leaves the bridge broken and creates a marked supply route. The desktop dialogue docks beside the actors, while portrait uses a tighter view and scrollable bottom panel. The portrait world still pans to reveal the full riverbank.
- **v0.2.0.** The v0.2 frame has a shallow foreground and a narrower bridge break; its workbench obscures the site. The v0.3 comparison shows the larger broken silhouette and the player carrying and fitting material within the world. The broad composition and light remain recognizably the same clearing. [Opening comparison](v030-screenshots/opening-comparison.jpg) · [Bridge states](v030-screenshots/bridge-states.jpg)
- **REGOLITH.** Inspected its pinned overhead rover frame. Terrain shading, deep shadows and track deformation make the rover feel grounded. Broken Bridge's register matches footsteps to the retained trail and changes the actual deck/flag/pack presentation, but it does not model continuous terrain deformation or a free 3D camera. [Pinned reference frame](https://raw.githubusercontent.com/winchxyz/moon-rover/f5f25ba6bf7477c612b408b265c9275a4fd1200d/docs/hero.jpg)
- **Paper Town.** Rendered its official Godot Web release in Chromium and inspected the open-book title and its closing interaction. Paper Town uses a textured physical book, a strong near focus and intentionally defocused scenery. Broken Bridge uses a live camera cut-in for Lin, layered foregrounds and world targets while retaining its own lighting and visual style. This comparison covered the accessible opening and book interaction. Full Paper Town traversal was untested. [Official Web release](https://github.com/100-Devs-1-Game/PaperTown/releases/tag/v2025.10.09-11)

## Verification gates

| Gate | Result |
|---|---|
| Gameplay and interaction | **PASS in Chromium**. Six state/language tests and four complete offline journeys across elementary/middle, bridge/ford, desktop and two touch viewports. Exercised actual pickup, carrying, wrong target, ordering, rotation, board fit, field action controls, delivery, keyboard/pointer movement, reset, save, export and reduced motion. Desktop ford also reloaded on the far bank. The same tests first reproduced the previous four v0.2.0 journeys before modifying the implementation. |
| Saves and review records | **PASS in Chromium**. The migration test created a partial v0.2 bridge save through real play and opened v0.3 on the same origin. The old board stayed installed and the preset response was labeled legacy. New export records preserve the student's own message and mark it for teacher review. |
| Internal visual evidence | **PASS** for capture and inspection of the target views. **NOT TESTED** for teacher creative acceptance. Portrait uses a scrolling camera and dialogue panel. |
| Curriculum | **NOT TESTED** for textbook, PPT, print and homework parity. The task incorporates illustrative route evidence. Both profiles now require a learner-authored message for a supported route. The completion floor and observation checks confer game progression. Language quality and meaning remain for teacher judgment. |
| Kokoro audio | **PASS** for exact 15-line mapping, MP3 decoding, normalized independent transcript comparison, offline playback fixture and in-game replay. **NOT TESTED** for teacher listening review of prosody, phoneme suitability and pronunciation detail. English voice only; Chinese remains visible as text. Approved Jesse audio was untouched. [Audio evidence](../audio/README.md) |
| Offline delivery | **PASS** for ZIP integrity, extracted standalone byte equality and browser execution with external requests denied. **NOT TESTED** for direct local-file launch on an unmanaged browser, native iPhone Safari, iOS Home Screen or WeChat. |
| Home release | **NOT TESTED**. Physical device verification, curriculum parity and language/audio suitability review remain open. |

## Reproduce

From the prototype folder run `npm test`, `npm run build`, then `python3 tests/browser.py`. The browser suite consumes the HTML extracted from the generated ZIP and saves actual frames under `test-results/v030`. The prior v0.2 source is tagged `broken-bridge-v0.2.0-baseline`.
