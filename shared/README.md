# Shared v8 game systems

Place reusable *engineering* systems here only after the first fully polished v8 vertical slice has validated them: navigation, save/export, dialogue UI, Chinese gloss overlays, reduced-motion controls, branching state, and QA helpers.

Do not copy story art, NPC identities, specific puzzles, or textbook copyrighted excerpts from the approved v6 example games. Shared code must be offline-compatible and unit-tested before reuse.
