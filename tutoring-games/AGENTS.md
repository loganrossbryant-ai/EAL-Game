# Scoped instructions — private tutoring EAL games

For any game under `tutoring-games/`, these instructions supplement root `AGENTS.md` and **must not import root's 80-minute secondary-school assumptions**. Read `../studio/README.md`, canonical source/visual/release standards, `standards/QUALITY_STANDARD_V1.md`, `standards/RELEASE_GATE.md` and latest authorized learner-specific teaching materials.

- Each learner/group has its own age, WIDA/phonics and class duration. Allen is not the default for all students.
- Full lesson-source mapping: textbook page, current PPT/print/homework, exposure/CORE/STRETCH, Chinese scaffolds, audio and in-game repeated meaningful production.
- Prefer a reusable approved engine **when it exists**, plus novel original story, setting, NPCs, assets and physical puzzles. Do not assume compiled Zig ZIP is editable source.
- Maintain approved references/recordings, including Jesse; use Kokoro for **new games**, locally bundled and pronunciation-checked. No browser speech substitutes, no false pronunciation scoring.
- Use authored ChatGPT image assets and the mandatory visual gate; one convincing 2.5D location before scaling; no vector/gameplay downgrade. Provide full navigation, physical puzzle, NPC, audio, mobile, QA and offline evidence.
- For full home-release status all `standards/RELEASE_GATE.md` gates pass, including actual target-device tests. No public student data or textbook scans in public git.
- Zig Lesson 4's archived PWA remains on `codex/tutoring-game-setup:tutoring-games/references/allen-lesson-4/` pending read-only centralized import; do not claim `validate_reference.py` exists on this branch or passed if the exact files are absent. Check manifest/hash and benchmark in its actual branch.
- Use `../studio/templates/` for new game production. Preserve functioning releases; branch, hash, rollback and report test evidence. No paid generation or deployment without approval.
